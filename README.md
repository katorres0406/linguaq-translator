# LinguaQ — Traductor con Qwen2.5-0.5B

**Traducción de idiomas 100% en el navegador, sin servidor, sin API keys.**

---

## 🌐 Demo en vivo

👉 **https://katorres0406.github.io/linguaq-translator/translator-2.html**

> Abrir en **Chrome** o Edge. La primera vez tarda 2-5 min en descargar el modelo (~300 MB).

---

## Ejemplos que funcionan

| Entrada (Inglés) | Salida (Español) |
|---|---|
| I like soccer | Me gusta el fútbol |
| How are you? | ¿Cómo estás? |
| What time is it? | ¿Qué hora es? |

---

## Tecnologías

| Librería | Uso |
|---|---|
| Transformers.js v3 | Inferencia en WebAssembly |
| Qwen2.5-0.5B-Instruct | Modelo de lenguaje |
| HTML + CSS + JS puro | Interfaz (sin frameworks) |
